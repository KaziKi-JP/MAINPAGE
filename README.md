# KKserver's Website

## Files
- `index.html` — page structure and content
- `style.css` — colors, layout, responsive design
- `script.js` — mobile navigation
- `assets/landscape.svg` — editable vector background illustration

## Preview
Open `index.html` in a browser. No build step or framework is required.

## Customize
- Change the page text and server details in `index.html`.
- Change the color palette in the `:root` section at the top of `style.css`.
- Replace `assets/landscape.svg` with your own background artwork if desired.
- Replace the sample Discord/social destinations with your actual invite and profile URLs before publishing.

The server names, addresses, membership counts, dates and profile details are sample content transcribed from the supplied reference design. Verify them before publishing.
